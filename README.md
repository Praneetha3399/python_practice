# Python Practice

A comprehensive Python learning repository focused on core fundamentals for automation testing and framework development.

## Project Structure

This project is organized into topic-based folders for easy navigation and learning:

### Core Data Structures
- **Dictionaries/** - Dictionary operations, methods, and use cases
- **Lists/** - List operations, filtering, and transformations
- **Strings/** - String manipulation, counting, and pattern matching
- **Tuple/** - Tuple operations and immutable sequences

### Object-Oriented & Functional Concepts
- **Functions/** - Function definitions, parameters, return values, and common patterns
- **Dict_Methods/** - Dictionary methods (get, keys, values, items)
- **List_Methods/** - List methods (append, extend, pop, remove, sort, reverse, etc.)

### Control Flow & Algorithms
- **Nested_Loops/** - Complex loop patterns, triangles, pyramids, and matrix operations
- **Exception_handling/** - Try-except blocks, file handling errors, and error management

### File & Data Processing
- **File_Handling/** - Reading, writing, and appending to files
- **Json/** - JSON parsing, serialization, and data transformation
- **Imports/** - Module importing and organization

## Topics Covered
- Loops and nested loops
- Functions and reusable code
- Strings (palindrome, frequency count, character operations)
- Lists (filtering, transformations, methods)
- Dictionaries (key-value operations, frequency counting)
- Exception handling and error management
- File I/O operations
- JSON data processing
- Pattern matching and algorithms
- Duplicate removal and data cleaning

## Getting Started

Each folder contains practice files and example problems. Start with the basic topics and progress to more complex patterns.

```bash
# Navigate to a topic folder
cd <topic_folder>/

# Run a practice file
python filename.py
```
